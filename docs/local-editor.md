# 本地编辑器使用与环境准备 / Local editor guide

[中文首页](../README_zh.md) · [English overview](../README.md)

本指南中的命令以包含 server/、web/、font/ 的产品目录为根目录。网页界面默认中文，简历内容可以是中文或英文。详细英文快速开始见 English overview；本页补充配置、数据格式与故障处理。

## 1. 准备环境

第一版保留源码、模板、字体和配置，没有打包 Node 或完整 LaTeX 发行版。用户需要：

- Node.js 22 或更新版本。可用 `node --version` 检查；验证使用 Node.js 24。
- 生成 PDF 时需要 MiKTeX 或 TeX Live 中的 XeLaTeX。安装发行版后重新打开终端，再使用已有的 XeLaTeX。仅编辑、保存和备份时可以暂时没有它。
- 模板需要 geometry、fontspec、xeCJK、titlesec、enumitem、tabularx、graphicx、fontawesome5、hyperref、accsupp 及它们的依赖。编译器可执行不代表宏包齐全。完整发行版可减少缺失；精简安装请根据错误日志手动补齐。
- 字体使用项目内的 Lato 和思源宋体（Source Han Serif，存放在历史名称 font/Simsun/ 下）。这些字体随源码提供，请保留 font/ 及其许可文件。

本地网页不需要 make、npm 依赖、前端构建、Docker 或购买服务器。make 与 fswatch 仅用于 README 中原 LaTeX 手工编译/监控方式。当前优先验证 Windows；Linux/macOS 入口提供源码运行方式，不代表完成这些系统的运行验证。

## 2. 启动与配置

Windows 运行 `start.cmd`，Linux/macOS 运行 `sh ./start.sh`，或在项目根目录运行：

```sh
node server/index.mjs
node server/index.mjs --no-open
```

第一条会尝试打开浏览器；第二条只显示网址。默认只监听本机 127.0.0.1:3000，在浏览器打开终端打印的网址。不要把本服务当作对外共享的服务器。终端需保持运行；按 Ctrl+C 停止。启动脚本按自身目录定位项目，直接 Node 入口也按脚本路径定位配置。

首次打开空数据目录会创建中文和英文虚构示例，可直接编辑。需要不同端口、数据目录或明确编译器路径时，把 `config.example.json` 复制为同目录的 `config.local.json`。例如：

```json
{
  "dataDir": ".purecv",
  "port": 3000,
  "xelatexPath": "C:/path/to/MiKTeX/miktex/bin/x64/xelatex.exe",
  "compileTimeoutMs": 90000
}
```

这是路径格式示例，需改成你机器上的实际位置。未设置 xelatexPath（null）时自动检测 PATH 与常见安装位置；明确设置后仅使用该文件，不会静默改用其他编译器。xelatexPath 指向可执行文件，不是目录。Windows 也可用双反斜杠转义路径；不要写单个反斜杠。dataDir 和编译器相对路径都以项目根目录为基准，不随终端当前目录改变。修改配置后停止并重启服务。

数据目录默认为 .purecv/；可指定其他可写目录。config.local.json 与默认数据目录已被 Git 忽略。改变数据目录后需自行添加忽略规则，尤其不要让真实数据进入公开仓库。

同一数据目录只允许一个服务实例，即使使用不同网页端口也不能同时打开。启动会先解析目录的实际路径并取得系统占用，再读取、初始化和恢复构建；正常停止或进程退出后系统释放占用，下次启动会把遗留运行记录标记为中断。更新源码前请先停止旧服务。

实现使用固定映射到本机 127.0.0.1:20000–39999 的系统端口占用，不写 PID 锁文件。极少数目录哈希碰撞、其他程序占用或系统保留端口也会使启动保守失败；它不会尝试换端口绕过保护。先关闭已有实例；仍失败可选择另一 dataDir，已有数据不会自动搬移，需按备份/迁移说明操作。

## 3. 日常编辑与 PDF

简历库可新建、选择或复制简历。基本信息、教育、工作/实习经历、项目、技能、奖项、社会活动分模块编辑；支持新增、删除、上下移动及隐藏模块，隐藏保留内容。要点编辑支持普通文字、加粗和链接，不直接输入 LaTeX 命令。

停止输入约 800ms 后自动保存。可以点击“保存”立即提交；等待状态显示已保存后再关闭服务。其他页面修改同一修订时会出现冲突，本页草稿会保留，可重新载入或复制草稿后处理；不要盲目覆盖。

PDF 需要手动点击“更新预览”。它会等待最新数据保存，捕获数据和校徽后编译；编辑时不自动触发编译。每次最多运行两遍 XeLaTeX，默认总超时 90 秒；服务同一时间仅运行一个构建。预览与下载使用同一个构建 ID。期间继续输入会提示预览落后于草稿；新内容失败时保留上次成功 PDF，核对显示的修订号再下载。每份简历保留最近五次成功构建及最近一次失败诊断。

预览区显示当前成功 PDF 的页数、多页调整建议，以及本次构建的简短警告。“查看本次编译日志”或“查看本次失败日志”打开该次固定构建的完整诊断；日志在任务结束后写出。失败日志对应本次尝试，旧 PDF 的页数、修订及下载仍对应上次成功构建。链接地址最多 2,000 字符，超限会在编辑器内提示并拒绝应用。

默认自动纸张：中文 A4、英文 Letter。也可选择明确的 A4/Letter、正文 10/11/12pt、标准/紧凑间距和 8–20mm 边距。标题有独立样式，正文大小不等于所有文字的大小。

中文与英文简历各自保存内容。复制为另一语言时会复制文字与校徽，调整模板和自动纸张；**需要手动翻译内容**。英文模板允许保留中文字符，但这不提供翻译服务。

## 4. 校徽

选择默认校徽、隐藏或上传自定义 PNG/JPG。上传上限 5MiB，宽度范围 1.2–3.2cm（默认 2.4cm），保持比例且最大高度 3.2cm。不支持 SVG、PDF 或任意文件路径。

自定义图片归属于单份简历；使用“复制”或“导出/导入备份”时会建立新的素材引用。隐藏校徽不删除上传图片，之后可恢复。更新图片后同样需要点击“更新预览”才能在新 PDF 中看到变化。

## 5. 备份与换机

侧栏“导出备份”得到可携带 JSON，包含当前内容、版式及自定义校徽；导出前会等待保存。保留的备份含个人信息，存放到自己信任的位置。另一台机器准备 Node、XeLaTeX 和完整项目文件后启动，选择“导入备份”；每次创建新简历与素材，不覆盖既有记录。备份上限 10MiB，损坏或超限文件会拒绝。

备份不包含 PDF 历史、编译环境或本地配置，导入后需重新生成 PDF。PDF 下载是阅读/投递成品，无法恢复可编辑模块。网页备份是首选搬迁方式。若另行复制整个 .purecv/ 数据目录，请先停止服务，复制完整目录，并配置新的 dataDir；config.local.json 中的本机路径也需要调整。

## 6. 一次性私有 JSON 导入

此入口仅面向已经人工整理好的数据，不解析任意 TeX。先在 .purecv/ 或其他明确忽略的私有目录准备 JSON：

```json
{
  "name": "我的中文简历",
  "data": {}
}
```

这里的空 data 仅展示外层格式，不能导入。data 必须完整满足 `web/shared/model.mjs` 的 ResumeData；公开虚构 `examples/resume.zh.json` 和 `examples/resume.en.json` 的整个对象都是 ResumeData，可作为外层 data 的结构参考，再人工填入。字段需严格匹配，不能添加旧记录 id、revision、任意文件路径或额外属性。name 是简历库标签，长度 1–2000 字符。

联系方式列表及每个模块的 items 列表内部，条目 id 必须唯一；重复 ID 会在保存或导入发布前被拒绝。不同模块之间可使用相同 ID；不会自动删除或合并重复内容。

在服务停止时执行：

```sh
node scripts/import-personal-data.mjs ".purecv/private-resume.zh.json"
```

数据文件路径相对于当前终端目录；配置与数据目录始终相对于脚本所在项目根目录。脚本只读取明确指定的文件，验证 name 和数据后新建 UUID；重复执行会得到另一份简历。标准输出只包含 name 和 id，不打印联系方式。重新打开网页可选择新记录。

此入口不携带图片，logo.assetId 必须为 null（默认或隐藏模式）；导入后在网页上传校徽，或使用包含图片的网页备份。输入 JSON 不是网页备份格式，二者不可互换。不要将真实资料复制到 examples/，也不要提交私有输入或 .purecv/。可在项目根目录运行 `git check-ignore .purecv/private-resume.zh.json` 确认忽略规则。

## 7. 常见故障

- **Node 不存在或过旧**：安装 Node.js 22+，重新打开终端；脚本提示缺失时不会启动服务。
- **未找到 XeLaTeX**：仍可保存和备份；检查是否装有 MiKTeX/TeX Live。已安装时确认实际可执行文件，再设置 xelatexPath 并重启。网页“环境与使用帮助”提供同样入口。
- **编译器已找到但编译失败**：检查页面显示的构建日志与错误。提示 `File '…sty' not found` 通常表示缺宏包，使用发行版管理工具手动补齐；检测只检查编译器，不探测或自动下载宏包。MiKTeX 实际编译禁止自动安装。请按自己选择的发行版处理，不需要重复安装字体。
- **字体或素材缺失**：确认移动项目时保留 font/、模板与默认校徽，必要时重新获取完整源码；不要手工编辑资产 ID。
- **端口占用**：config.local.json 修改 port 后重启，使用新网址。
- **无法取得数据目录独占权**：先关闭同一数据目录的其他实例；更改网页 port 不能绕过此限制。若没有其他实例，可能是系统保留或其他程序占用了保护端口，按上文说明选择另一 dataDir。
- **浏览器未自动打开**：手动访问终端显示的本机网址。
- **保存或备份失败**：检查数据目录可写及剩余空间，保留草稿；不要把“编译成功”当作未保存修改的保证。

原 LaTeX 手工方式和正确编译子目录仍见两个 README。网页生成文件保存在数据目录独立构建中，不覆盖原 resume/、resume_zh/、字体、校徽和已有 PDF。
